# R Script Example

Demonstrates best practices for R scripts including:
- File headers with metadata
- Function organization
- Meaningful variable names
- Comments for complex logic
- Error handling
- Modular design

## Files

- `analysis.R` - Main analysis script with functions and execution logic

## Running the Example

```r
source("analysis.R")
```

Or from command line:
```bash
Rscript analysis.R
```

## Best Practices Demonstrated

✓ File header with purpose, author, date  
✓ Library imports at top  
✓ Functions before main code  
✓ Input validation  
✓ Consistent naming (snake_case)  
✓ Comments for non-obvious logic  
✓ Modular helper functions  
✓ Proper error handling  

## Validation with r-practices

```bash
r-practices validate .
r-practices detect .
```
